# Freight Proof Pay

For FreightProof AI, I recommend a clean, premium B2B SaaS identity that communicates three things immediately: trust, financial control, and transportation verification.

Based on your startup blueprint, the logo should represent more than freight logistics. It should convey how your platform verifies transport invoices against contracts and shipment evidence before payment.

1. Logo and brand identity

Proposed logo and visual identity for FreightProof AI.

The logo uses an F-shaped shield with a road and checkmark to connect freight movement with verified financial transactions. The blue-and-green combination makes it feel like an enterprise finance platform rather than a conventional transport company.

## Experience
Build a polished, responsive transportation-spend review workspace from the supplied blueprint and brand guide. The first screen is an invoice-audit dashboard, not a marketing-only page. Use the FreightProof AI identity, Montserrat headings, Inter interface text, navy/blue surfaces and orange accents; clearly identify sample figures as illustrative.

## User workflows
- Navigate an overview, invoice queue, contracts, evidence, recovery and reports within the workspace.
- Search and filter sample invoices, open an invoice to inspect its line-item checks and evidence, then record an approval, evidence request or dispute.
- Select an invoice file for the review queue and export the visible invoice list as CSV.
- Keep the sample-data demo self-contained; do not imply documents are actually OCR-processed or decisions are persisted to a company account.

## Technical details
- Replace the root index placeholder with the workspace, using existing shadcn controls and semantic CSS tokens.
- Use browser-side state for the interactive demo, with no new database, authentication, server functions or dependencies.
- Give the home route its own FreightProof-specific search/social metadata and update the shared font and favicon links to match the brand.
- Validate through the existing routing test, the preview build signal and a browser pass through search, invoice review/actions and file selection.
